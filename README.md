## What I Work On

I have experience developing projects that combine software engineering and optimization, including the implementation and comparison of heuristic and metaheuristic algorithms.

Some of the approaches I've worked with include:

```text
Problem
   │
   ├── Mathematical Modeling
   │       └── MIP / Constraints / Objective Functions
   │
   ├── Exact Methods
   │       └── CPLEX / Gurobi / HiGHS
   │
   └── Heuristic & Metaheuristic Methods
           ├── GRASP
           ├── Local Search
           ├── Tabu Search
           └── Simulated Annealing
```

I'm particularly interested in comparing solution quality, computational performance, and scalability across different optimization approaches.
